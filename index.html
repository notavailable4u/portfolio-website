About Me

My path to development started with a Web Design Diploma in 2007. I completed CareerFoundry’s Full Stack Web Development qualification in September 2024 and now focus on frontend work with React.

In IT support, I learned to listen to users, investigate problems, and learn unfamiliar systems. I bring those habits to development: working through issues methodically and considering how an interface will be used.

My recent projects include a weather app using the Open-Meteo API and a configurable testimony card component. I’m continuing to develop my React skills through projects and coursework.
